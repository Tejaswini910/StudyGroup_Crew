# Study Group Crew

An interactive Streamlit study assistant for researching subjects, turning a topic and optional syllabus text into study notes, taking scored multiple-choice quizzes, and reviewing past sessions.

## Run Locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

In GitHub Codespaces, open the forwarded **Study Group Crew** port (8501) from the **Ports** panel.

Choose a subject or enter your own, type any topic, optionally paste relevant syllabus or class material, and choose 3-10 quiz questions. The app searches Wikipedia and the supplied syllabus, generates a study pack, runs a structural fact-check, and saves the report.

## Agents and Context Flow

- **Topic Researcher** searches Wikipedia and syllabus content, then passes source extracts and IDs to the next agents.
- **Study Explainer** turns those sources into structured, cited notes and hands them to the Quiz Maker.
- **Quiz Maker** creates multiple-choice questions, answer keys, and explanations from the notes and sources.
- **Fact-Checker** validates source IDs, answer keys, options, and explanations before the pack is saved.

The LangChain tools are `wikipedia_search`, `syllabus_content_search`, and `verify_study_materials`. Wikipedia requires internet access. Syllabus text is searched locally and is not sent to Wikipedia. The fact-checker validates structure and references; it does not prove every subject claim independently.

## Optional Local AI

The repository did not include CrewAI, Ollama, or another model provider. The app can use a locally running Ollama server without an API key. Install Ollama separately, pull a model, and start its local service:

```bash
ollama pull llama3.2
OLLAMA_MODEL=llama3.2 streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

Set `OLLAMA_BASE_URL` if Ollama is listening somewhere other than `http://localhost:11434`. No cloud API key is used or required. When no local model is configured, the app clearly labels its source-grounded extractive fallback; quiz and note text in that mode is not newly generated by an LLM.

## Saved Files

- `outputs/study_group_output.md`: latest study pack.
- `outputs/study_reports/`: one Markdown report per study session.
- `outputs/study_history.json`: session metadata and submitted quiz scores.
- `outputs/study_group_reflection.md`: assignment reflection covering what worked, failed, and possible improvements.

The Streamlit app also provides download buttons for individual study packs, past reports, and the history JSON.
